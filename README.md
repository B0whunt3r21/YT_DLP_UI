# YT_DLP_UI
Small Textual UI for YT_DLP (https://github.com/yt-dlp/yt-dlp)

 ## Supports:
  - YT-links
  - Twitch-links

YT links will automatically be shortened to just the current video, to prevent accidental mass-downloads.


> [!IMPORTANT]
> Should pasting a link into the URL-Field not work, try pressing "CTRL + SHIFT + V" instead.
